### Selected work
*Bread Financial &middot; customer &amp; account domain*

**Core applications onto Azure**

Led the migration of core customer-facing applications to Azure, containerized on Kubernetes and Docker, and moved the Account API onto Azure Kubernetes Service for scale and resilience. Then built the monitoring that wasn't there &mdash; dashboards and alerts for the most critical services, the standards behind them, and coaching for lead engineers in other domains so they could do the same. One tuning pass took a chatty service from roughly 8,000 calls in a ten-minute window to under 500.

`−20%` infrastructure cost &middot; `+25%` system reliability &middot; `8,000 → <500` calls / 10 min after tuning
Azure &middot; Kubernetes / AKS &middot; Docker &middot; Grafana / Prometheus &middot; ServiceNow / CMDB

**APIs customers can serve themselves with**

Designed and delivered the REST APIs and self-service features behind customer-facing journeys &mdash; more people finishing the task themselves, fewer of them calling to finish it. The largest was a consent API built from the ground up as tech lead, introducing Kafka to the team's ecosystem for event-driven processing and OAuth2 for a secure partner integration. It now ships in daylight, with a documented rollback plan and validation passing every time.

`+15%` customer engagement &middot; `−10%` support cost
Java / Spring Boot &middot; Apache Kafka &middot; OAuth2 &middot; REST
